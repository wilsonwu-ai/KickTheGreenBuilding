What we claim we measure

We do not claim to measure kick force. A football leaving a foot carries force we never see. What is honestly measurable with cheap hardware is ball velocity and impact location — a radar module or a 120 fps camera gives both. Real impact force needs an instrumented target: a piezo or load-cell backing board. The scoring model here takes velocity and impact point as ground truth and calls power an estimate, with a calibration constant you set against a radar reading. Say that out loud in the demo; it is the difference between a toy and a prototype.

Display driver (d54 plugin interface)

// 153 windows = 9 cols x 17 rows, 24-bit, 15 fps ceiling.
public class KickPlugin extends DisplayPlugin {
  private final FrameQueue q; // fed by the scoring service

  public KickPlugin(Display2D d, double framerate) {
    super(d, framerate);
    q = FrameQueue.subscribe("ws://scoring.local/frames");
  }

  public void loop() {
    Frame f = q.poll();               // 459 bytes: 153 x RGB
    if (f == null) return;
    for (int y = 0; y < 17; y++)
      for (int x = 0; x < 9; x++)
        getDisplay().setPixel(x, y, f.rgb(x, y));
  }
}

Frame format on the wire

Every frame this page generates is emitted in the exact shape the bridge expects, and the wire monitor above shows them live. Row 0 is floor 18; row 16 is floor 2 — the first floor has no lights. Export a kick and you have a replay file you can pipe straight at the building or at the Java preview window.

Safety and approvals, honestly

Nobody kicks toward the building. The target is a netted rebound goal facing away from the facade, on the Great Sail lawn — the same spot the 2012 Tetris controller sat, about 70 m out. The facade is the output; the ball never goes near it. That framing is what makes the approval conversation short.

Simulation of the permanent LED installation hacked into the Green Building in April 2012: 153 wirelessly controlled RGB lights, one in every window above the first floor, 9 across and 17 up. The building is 18 floors and 277 ft, which MIT counts as 21 stories — the floor meter uses stories, the window grid uses lit floors. Ball speed is an estimate derived from input intensity, not a radar measurement.
